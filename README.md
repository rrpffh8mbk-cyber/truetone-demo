# 试色有谱 · TrueTone

**同一支口红，哪条试色值得参考？**

不是看到一张漂亮照片就做购买决定。试色有谱先比较同产品的照片颜色与文案依据，再从可追溯的真人体验中优先找条件相近的证据。

[体验网站](https://rrpffh8mbk-cyber.github.io/truetone-demo/) · [演示与验证协议](docs/DEMO_PROTOCOL.md) · [数据来源](DATA_PROVENANCE.md) · [运行检查](tests/README.md)

## 正式演示只证明三件事

1. **同一支口红为什么看起来不一样**：自动找唇部、对照对应版本的标准图，分别展示颜色差异与版本不确定性。不能凭色差断言修图或真假。
2. **哪些证据值得参考**：检查本人条件、具体使用体验和绝对承诺；消费者支持与不同体验保留原文，不用好评率代替证据。
3. **哪些证据更接近你**：在可靠样本中结合已确认的唇色、肤色、妆面推荐 TOP3。原生唇色只采用作者明确自述；条件缺失不补猜。

首页主入口是“检查一条种草”，不填写个人条件也可使用。附件提供的三个固定案例已加入一键体验：夸张种草、274 版本混淆、具体使用体验。点击后由同一算法实际分析，不读取预设结果。它们是已知演示/压力测试案例，**不能当作独立盲测、准确率或跨品牌泛化证明**。

自拍颜色与质地预览、相似方向和色号对比是辅助功能。个人参考色最多采用 5 张条件相近且来源不重复的图片；条件都未知的图片单列，不混入个人取色。预览是视觉模拟，不是精准商业 AR 试妆。

## 分数各回答一个问题

- **颜色相似度**：唇部 CIEDE2000 色差，0 对应 100，30 及以上对应 0；不代表真实性概率。色号报告的分数只显示已筛选照片的相似度中位数，筛选偏差明确说明。
- **文字参考分**：从 0 累计本人条件、涂抹厚度、颜色描述、时间/使用变化、具体体验、正反体验和表达边界；绝对承诺扣分并限制上限。自然光/无滤镜/原相机只是声明，不因此加分。负面体验作为信息，不自动扣分。逐项计算可展开查看。
- **图片推荐排序**：四个职责的确定性质量评估（40/30/20/10），质量 70% + 已确认标签匹配 30%；不是四个独立模型的置信度。可追溯的图片哈希提供来源完整性信息，无滤镜自述不获得额外质量分。

图片、文案与个人匹配分别解释，**不合成一个“真假总分”**。

## 当前边界

深入覆盖 **4 个色号**：YSL 610、1936，Lancôme 274、275。274 保留 Cream / Cream Gift / Intimatte 的版本边界，无法确定时按家族级解释，不默认某版。

检查 169 张原始样本和 6 张标准图，151 张样本用于颜色参考、18 张保留不使用原因；2,093 条原始文字记录去重为 1,913 条。数量是当前证据规模，不能代表总体市场。尚未完成独立人工标签、盲评或 Accuracy/F1 评估；尚不能宣称适用于所有口红。不支持的产品不生成伪造报告。

## 对品牌的具体交付

色号报告可下载本色号的“素材改进清单”：现有证据 → 补充版本/拍摄条件/使用变化 → 关联图片与评价 ID → 待执行验证指标。清单不自动发布素材，不声称已接入品牌系统或获得转化提升。先验证消费者理解度，再设计同条件的 A/B 测试。

## 核心机制与代码

| 机制 | 实现 |
| --- | --- |
| 同产品、同版本边界与可追溯证据 | `review-text.js`、`data/catalog/`、`demo-cases.js` |
| 可比较的唇部颜色 | `semantic-lips.js`、`lips.js`、`color-similarity.js` |
| 文案信息与表达边界 | `evidence-assessment.js` |
| 已确认标签匹配与证据排序 | `library-tags.js`、`personal-color.js` |
| 品牌素材改进清单 | `brand-actions.js` |
| 辅助视觉预览 | `tryon.js`、`lip-finish.js` |

BiSeNet / MediaPipe / CIELAB 是实现工具；核心是同产品证据筛选与解释，不声称这些已有算法是原创模型贡献。

## 本地运行

```sh
python3 -m http.server 8000
```

检查方法见 [tests/README.md](tests/README.md)。原始大文件在用户上传的 GitHub Release `data_original`，仓库保存派生数据、缩略图与使用记录。公开前端不保存大模型 API Key，云端语言整合失败时仍可运行本地证据分析。
